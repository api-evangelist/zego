# Zego

> Zego is an FCA-regulated UK insurtech providing flexible, telematics-based motor and public-liability insurance for gig-economy drivers and couriers, private-hire taxis, vans, fleets and learner drivers. It also exposes a partner API for work providers to activate cover and manage customers on behalf of Zego customers.

## APIs
- [Zego Partner API docs](https://developer.zego.com/): RESTful partner API for shifts, customers, policies, occupations and customer matching (base URL https://api.zego.com).
